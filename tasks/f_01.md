## 0.1 Добавить React Error Boundary (`main.tsx`)

**Проблема:** Нет Error Boundary — при ошибке в `App` приложение полностью падает без recovery.

**Действия:**
- [ ] Создать `src/ui/ErrorBoundary.tsx` с `componentDidCatch`
- [ ] Обернуть `<App />` в ErrorBoundary в `main.tsx`
- [ ] Показать пользователю кнопку "Restart" и логи ошибки в dev-режиме

**Ожидаемый результат:** Приложение не падает при ошибках рендеринга, есть graceful degradation.

## 0.2 Добавить type-safe EventBus (discriminated union payloads)

**Проблема:** `EventBus.payload` имеет тип `Record<string, unknown>` — никаких compile-time проверок, любой consumer должен вручную type-check payload.

**Действия:**
- [ ] Определить `type GameEventMap = { [event]: { typed payload } }`
- [ ] Заменить `payload: Record<string, unknown>` на `K extends keyof GameEventMap ? GameEventMap[K] : never`
- [ ] Обновить все `eventBus.publish()` вызовы с типизированными payload
- [ ] Обновить все `eventBus.subscribe()` handlers

**Ожидаемый результат:** Компилятор предотвращает отправку/приём неправильных payload.

## 0.3 Добавить TypeScript check на i18n ключи

**Проблема:** Нет проверки консистентности RU/EN ключей — пропущенный ключ в одном словаре производит garbled output.

**Действия:**
- [ ] Создать `scripts/check-i18n-consistency.ts` — скрипт сравнивает keys в ru и en словарях
- [ ] Добавить в `tsconfig.json` проверку: ключи `en` должны совпадать с `ru`
- [ ] Добавить в `package.json` команду `npm run check:i18n`
- [ ] Добавить в CI workflow

**Ожидаемый результат:** TypeScript/compiler блокирует mismatch ключей при сборке.
