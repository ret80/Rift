# ref_03 — Удалить dead code: WaveManager

## Проблема

`src/game/wave/WaveManager.ts` (309 строк) **нигде не используется**.

WaveManager реализует:
- Генерацию волн (`getWaveConfig`)
- Планирование спавна (`planSpawns`)
- Очередь врагов (`spawnQueue`)
- Таймеры спавна (`spawnTimer`)

Но в `game.ts` нет ни одного импорта или использования `WaveManager`. Реальная работа с волнами делится между:
- `WaveOrchestrator` — жизненный цикл волны, зона, edge danger
- `SpawnSystem` — физический спавн врагов из разломов
- `game.ts` — счётчики `wave`, `waveTotal`, `allocated`, `killedWave`

## Цель

Удалить `WaveManager.ts` и все vestigial ссылки на него.

## Задачи

### 1. Убедиться в отсутствии ссылок

```bash
grep -r "WaveManager" src/
```

Если `WaveManager` нигде не импортируется — удалять безопасно.

### 2. Удалить файл

```
src/game/wave/WaveManager.ts
```

### 3. Очистить директорию

Если `src/game/wave/` становится пустой — удалить всю директорию.

## Критерии готовности

- [ ] `grep -r "WaveManager" src/` возвращает ничего (кроме этого файла)
- [ ] `npm run typecheck` без ошибок
- [ ] Проект собирается (`npm run build`)

## Ожидаемый эффект

- Удалить ~309 строк dead code
- Сократить размер бандла (мёртвый код не попадёт в production)
- Убрать путаницу: одна система волн вместо двух (одна рабочая, одна нет)

## Зависимости

Нет. Можно делать сразу.
