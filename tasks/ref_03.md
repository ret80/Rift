# ref_03 — Спавн врагов и управление разломами

## Цель
Враги появляются ТОЛЬКО из разломов. В меню — разлом в центре экрана, враги летают и исчезают за пределами. В игре — враги не умирают за пределами камеры, все должны быть убиты игроком.

### Task 3.2: Улучшить MenuScene — центрированный разлом

**Текущее состояние:** Разломы спавнятся в случайной позиции на экране.

**Задача:** Сделать центральный разлом из которого спавнятся враги.

**Решение:**
```typescript
// MenuScene.ts — spawnMenuRift():
private spawnMenuRift() {
  // Разлом спавнится в центре экрана
  const x = 0;  // Центр экрана (world coords: 0, 0)
  const y = 0;
  
  const count = 1 + Math.floor(Math.random() * 3);
  const kinds: EnemyKind[] = [EnemyKind.Drone, EnemyKind.Hunter, EnemyKind.Fighter]
    .slice(0, count);
  
  this.menuRifts.push({
    x, y,
    t: 0,
    state: "opening",
    queue: kinds,
    // ...
  });
}
```

### Task 3.3: Игровые враги — не удалять за пределами камеры

**Текущее состояние:**
- `EnemySystem.update()` принимает `enemyList` и обновляет позиции
- Нет явного удаления врагов за пределами камеры
- `EnemySystem.removeDead()` фильтрует только мёртвых

**Проверка:** Где удаляются враги за пределами камеры?

**Результат:** В `CollisionSystem.ts` нет удаления врагов за пределами. Враги не удаляются если улетели за экран.

**Задача:** Добавить проверку в `EnemySystem.update()` или в `game.ts step()`:
```typescript
// В EnemySystem.update():
// Удалить врагов которые улетели очень далеко (только для menu, НЕ для игры)
removeFarAwayEnemies(maxDist: number): void {
  this.enemyList = this.enemyList.filter(e => {
    if (e.dead) return false;
    const dist = Math.hypot(e.x, e.y);
    return dist < maxDist;
  });
}
```

**ВНИМАНИЕ:** В игре враги НЕ должны удаляться! Только в меню.
