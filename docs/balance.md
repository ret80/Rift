### 15.5. Мета-экономика (кредиты)

| Действие | Кредиты |

| Забег (базовый) | 5% от деталей |
| Чистая зачистка волны | +50% деталей волны → +кредиты |
| Graze (5 касаний) | +1 деталь → +0.05 кредита |
| Комбо (×2) | +100% деталей за убийство |
| Быстрая зачистка (<60с) | +25% деталей |
| Убийство элиты | +10 деталей |
| Убийство босса | +50 деталей |
| Якоря (все уничтожены) | +40% деталей волны |
| Минимум за забег | 1 кредит |

**Цель:** 1 забег (15–30 мин) → 50–200 кредитов. Полное мета-дерево: ~10 000 кредитов [TUNE]. Это ~50–100 забегов (25–50 часов).
