# Запись геймплея и калибровка агента

Короткая инструкция: как записать забег, прогнать симуляцию и что делать с итоговым отчётом.

## 1. Запись

```bash
npm run dev
```

1. Открой игру в браузере.
2. В меню нажми **F9** — запись взведена, в HUD появится `REC: ARMED`.
3. Начни забег. Запись стартует с тика 0, поэтому будет `replayable=true`.
4. Остановить запись можно так:
   - **F9** — вручную;
   - свернуть окно или потерять фокус — запись остановится и сохранится;
   - смерть (`game over`) — сохранится автоматически.
5. Браузер скачает `rift-session-<id>.jsonl`.

Рекомендуемое место хранения:

```text
sim-results/sessions/
```

Каталог в `.gitignore`: записи — локальные данные, не коммитятся.

> F9 нужно нажимать **до старта забега**. Если включить запись во время игры, она будет partial (`replayable=false`): профиль и калибровка работают, точный реплей — нет.
>
> В прод-сборке запись выключена; для отладочной сборки её можно включить через `?debug=1`.

## 2. Проверка записи

```bash
npm run sim -- sessions validate sim-results/sessions/rift-session-<id>.jsonl
npm run sim -- sessions show     sim-results/sessions/rift-session-<id>.jsonl
```

`validate` должен завершиться с кодом 0. `show` покажет seed, длительность, волну, число интентов, checkpoint-ов и причину завершения.

## 3. Профиль игрока

```bash
npm run sim -- profile sim-results/sessions/rift-session-<id>.jsonl
```

Вывод — измеренные признаки: реакция, ошибка прицела, предпочитаемая дистанция, доля огня, край зоны, способности и интенсивность движения. Для машинного формата добавь `--json`.

## 4. Реплей

```bash
npm run sim -- replay sim-results/sessions/rift-session-<id>.jsonl
```

Ожидается `точное совпадение`: мир воспроизводится бит-в-бит по записанным интентам.

Проверка чувствительности к балансу:

```bash
npm run sim -- replay sim-results/sessions/rift-session-<id>.jsonl --balance enemyHpMult=1.1
```

Ожидается расхождение до 600-го тика. Метрики после первого расхождения считаются невалидными.

## 5. Калибровка и итоговый отчёт

```bash
npm run sim -- calibrate sim-results/sessions/rift-session-<id>.jsonl \
  --runs 3 \
  --balance enemyHpMult=1.0,2.0,3.0,4.0 \
  --out sim-results/calibration/2026-11-04/report.json
```

Появятся два файла:

- `report.md` — читать человеку: профиль, параметры агента, матрица, реплей, чек-лист и ограничения;
- `report.json` — машинный отчёт для повторных прогонов и CI.

Матрица `1.0–1.2` часто не чувствительна: при текущем уроне враг умирает с одного выстрела, и шаг 5–20% ничего не меняет. `1.0, 2.0, 3.0, 4.0` даёт заметный отклик.

Флаг `--runs` задаёт число seed (по умолчанию 3: seed записи и два следующих). `--balance` принимает несколько ключей через `;`, например:

```bash
--balance "enemyHpMult=1.0,2.0;enemyDamageMult=1.0,1.1"
```

Только параметры, без прогонов:

```bash
npm run sim -- calibrate sim-results/sessions/rift-session-<id>.jsonl --dry-run
```

## 6. Что делать с отчётом

В `report.md` смотри:

1. **Профиль записи** — что измерено у игрока.
2. **Параметры EvadeAgent** — что получилось после калибровки.
3. **Матрицу** — `D_cal` против `D_def`, `survivalTime`, `damageTaken`, `waveReached`.
4. **Реплей** — R0 должен совпасть, R1 — разойтись.
5. **Чек-лист**:
   - `improvesOverDefault` — калиброванный агент ближе к записи, чем дефолтный;
   - `balanceResponds` — матрица реагирует на рост HP;
   - `distanceGood` — `D ≤ 0.25`.

Запустить калиброванного агента из стартового контекста записи:

```bash
npm run sim -- run --from-session sim-results/sessions/rift-session-<id>.jsonl \
  --agent calibrated \
  --calibration sim-results/calibration/2026-11-04/report.json
```

Либо взять `calibration.agent.params` из JSON и передать их в `EvadeAgent` вручную.

Баланс автоматически **не меняется**: отчёт — это измерение, а не автокоррекция. Одна запись не является основанием для балансировочных выводов; для решения нужно несколько записей и сравнение отчётов.

## 7. Если что-то не работает

| Симптом | Причина |
|---|---|
| F9 ничего не делает | Это прод-сборка без `?debug=1`; запись доступна только в dev. |
| Запись `partial`, реплей запрещён | F9 нажат во время забега, а не в меню. |
| Нет скачанного файла | Браузер заблокировал скачивание; нажми F9 ещё раз или проверь загрузки. |
| `sessions validate` возвращает 1 | Файл обрезан или не JSONL; смотри номер строки в ошибке. |
| Матрица не реагирует на баланс | Слишком узкий шаг HP; используй `1.0, 2.0, 3.0, 4.0`. |

## 8. Проверка конвейера без человека

Синтетическая сессия тем же рекордером:

```bash
npm run sim:fixture -- --out sim-results/sessions/synthetic.jsonl --seconds 120 --seed 1
```

Она проверяет работоспособность конвейера, но не заменяет человеческую запись: стиль агента — не стиль игрока.

Подробности реализации и результаты эксперимента — в `tasks/agent-calibration-from-recordings-plan-2026-11-03.md` (§14).
