## 8. Экономика забега

### 8.1. Источники деталей (parts)

| Источник | Количество |
|---|---|
| Убийство дрона | 3 |
| Убийство хантера | 6 |
| Убийство истребителя | 7 |
| Убийство крейсера | 16 |
| Убийство носителя | 32 |
| Убийство минёра | 10 |
| Убийство элиты | ×1.5 от базы |
| Убийство босса | ×3 от базы |
| Зачистка волны | 15 + 6×w |
| Graze | 1 деталь за 5 касаний (≤20/волну) |
| Комбо | ×1.0–×2.0 множитель за убийство (зависит от комбо-счётчика) |
| Чистая зачистка | +50% деталей за волну (без полученного урона) |
| Быстрая зачистка | +25% (волна < 60с) |
| Якоря | +40% деталей за волну (если все уничтожены) |
| «Страховка за выживание» | УДАЛЕНА (заменена graze/комбо) |

### 8.2. Мастерская между волнами

- Улучшения текущего забега (корпус, скорость, оружие, дроны, щит, темп огня, длительности).
- Цены: базовые из `UPGRADE_TIERS` (см. раздел 15).
- [P1] Снижение цен через мета-таланты (−10%/−20%/−30%).
- [P1] «Реролл» магазина за 50 деталей (мета-талант).


### 8.4. Graze и комбо

- **Graze:** полоса 22px вокруг хитбокса. Касание пули без урона = 12 очков + 1 деталь за 5 касаний.
- **Комбо:** множитель очков ×1.0–×10 за последовательные убийства без паузы > 3с. Множитель деталей за убийство = 1.0 + (comboLevel × 0.1), кап ×2.0.
