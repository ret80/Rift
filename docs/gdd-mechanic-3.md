## 1. Обзор и концепция

### 1.1. Жанр и сеттинг

РАЗЛОМ — аркадный **bullet hell на замкнутой круговой арене** с автоприцелом. Игрок управляет кораблём; основной ввод — направление тяги, оружие и дроны стреляют сами по ближайшей цели. Фокус смещён с прицеливания на **выживание, контроль пространства и чтение паттернов**.

### 1.2. Elevator pitch

> «Смерть — это не конец, а только досадное недоразумение.»  
> Каждый забег начинается с нуля, но каждая смерть инвестирует в мета-прогресс. Игрок наращивает мастерство и мощь одновременно, а асценсия даёт бесконечный вызов.

### 1.3. Целевая аудитория

- Любители bullet hell / shoot 'em up (Touhou, Geometry Wars).
- Любители roguelite (Hades, Vampire Survivors, Dead Cells).
- Игроки, ценящие «just one more run» и мастерство.

### 1.4. Ключевые pillars

1. **Край не безопасен, центр не обязателен.** Безопасность — функция чтения угроз и манёвра, а не радиуса.
2. **У каждой угрозы есть ответ, у каждого ответа — цена.** Атаки телеграфируются; ресурс (энергия, КД) не даёт спамить.
3. **Каждая покупка добавляет глагол, а не процент.** Новое оружие/роль/доктрина меняет то, что игрок *делает*.
4. **Награда пропорциональна риску и мастерству.** Чистая зачистка, graze, комбо, элиты конвертируются в прогресс сильнее пассивного выживания.
5. **Смерть — инвестиция.** Мета-прогресс делает поражение не наказанием, а шагом вперёд.

### 1.5. Платформы и сессия

- Платформа: Web (Vite + React), десктоп и мобильный ввод (клавиатура/геймпад/тач).
- Длительность забега: **15–30 минут** (цель — короткие забеги для «ещё один раз»).
- Длительность сессии: 1–3 забега (30–90 мин).

## 2. Core Loop (ядро геймплея)

### 2.1. Высокоуровневый цикл

```
Выбор доктрины + экипировка Наследия
        ↓
Забег: волны 1..N, магазин между волнами
        ↓
Смерть или победа (волна 10/20/... босс)
        ↓
Начисление кредитов + разблокировки + артефакты
        ↓
Мета-дерево: покупка талантов, разблокировка оружия/дронов
        ↓
(После первой победы) Повышение Threat Level
        ↓
Новый забег
```

### 2.2. Микро-цикл внутри волны

```
Спавн врагов (30% сразу, далее подкрепления)
        ↓
Бой: тяга, форсаж, активный щит, выбор цели, приказы дронам
        ↓
Сбор деталей, graze, комбо
        ↓
Якоря-разломы: сходить к якорям и закрыть разломы, иначе волна не закончится
        ↓
Зачистка → экран результатов → магазин → следующая волна
```

### 2.3. Что игрок делает каждую секунду

- Читает угрозы (телеграфы, очередь атакующих, радар).
- Принимает позиционные решения (радиус, направление, смена позиции).
- Использует активные глаголы (форсаж, щит, лок цели, приказы дронам).
- Собирает детали и пикапы.
- Решает, идти ли к якорю или катать по краю.

## 3. Механика 3: прогрессия, мета, асценсия

### 3.1. Три слоя прогрессии

| Слой | Сброс при смерти | Валюта | Что даёт |
|---|---|---|---|
| **Забег (run)** | Да (всё) | Детали (parts) | Улучшения текущего забега: корпус, скорость, оружие, дроны, щит, темп огня |
| **Мета** | Нет | Кредиты (credits) | Таланты Зеркала, разблокировка оружия/дронов/способностей, снижение цен |
| **Асценсия** | Нет | Threat Level (TL) | Модификаторы сложности, новые аффиксы, новые арены |

### 3.2. Девиз

> «Смерть — это не конец, а только досадное недоразумение.»

Смерть сбрасывает забег, но инвестирует в мета. Игрок никогда не «теряет время».

### 3.3. Кредиты: прогрессивная формула

```
credits = floor(basePercent * totalParts + masteryBonus)

basePercent = 0.05 (5% от собранных деталей за забег)
masteryBonus = sum of:
  - cleanWaveBonus: +50% деталей волны, если урон не получен
  - grazeBonus: 1 деталь за 5 касаний (≤20 за волну)
  - comboMultiplier: до ×2 деталей за убийство (комбо)
  - fastClearBonus: +25% деталей, если волна зачищена < 60с
  - eliteKillBonus: +10 деталей за элитного врага
  - bossKillBonus: +50 деталей за босса
  - anchorBonus: +40% деталей за волну с якорями (если уничтожены все)
```

**Правило:** кредиты начисляются **всегда**, даже при смерти на 1-й волне (минимум 1 кредит за участие [TUNE]).

### 3.4. Разблокировки (Unlocks)

Разблокировки — отдельный слой от кредитов. Открываются за **достижения** (achievements), как в Vampire Survivors:

| Достижение | Разблокировка |
|---|---|
| Убить 100 дронов | Дрон «Разведчик» |
| Убить 50 хантеров | Дрон «Штурмовик» |
| Пройти 10-ю волну | Оружие «Ракета» |
| Пройти 20-ю волну | Оружие «Лазер» |
| Пройти 20-ю волну без урона | Доктрина «Стеклянная пушка» |
| Собрать 10 000 деталей за всё время | Талант «Магнит» в мета-дереве |
| Убить босса на 10-й волне | Артефакт «Перо Феникса» |
| Достичь 50-й волны | Threat Level 1 |
| ... | ... |

Полный список — в разделе 9.3.

### 3.5. Победа и асценсия

- **Первая победа:** убийство босса на 10-й волне (или достижение 10-й волны).
- После первой победы открывается **Threat Level 1** (асценсия).
- Игрок может повышать TL, добавляя модификаторы (раздел 12).
- Каждый TL повышает награду (кредиты ×1.1, детали ×1.05 [TUNE]).

## 4. Забег: волны, зона, спавн, цели

### 4.1. Волны

| Параметр | Значение |
|---|---|
| Врагов на волне | 24 + 1.35·(w−1), потолок 64 (≈31-я волна) |
| HP врагов | ×1.0 → ×2.5 к 40-й волне |
| Урон врагов | ×1.0 → ×2.95 к 40-й волне |
| Меткость врагов | 0.30 + 0.012·w, потолок 0.70 (≈34-я) |
| Босс | каждые 10 волн (10, 20, 30, ...) |
| Якоря-разломы | каждая 3-я волна, начиная с 3-й |

### 4.2. Зона

| Параметр | Значение |
|---|---|
| Радиус зоны | 380 + 10·(w−1), потолок 650 px |
| Расширение | 1.3 × текущей максимальной скорости игрока |
| Урон вне зоны | 10% макс. корпуса/с (пульсы 0.5с) |
| Фазы волны | расширение → удержание (45с) → сжатие к 0.35R (скорость 0.55× игрока, телеграф 3с) |
| Буря на кромке | внешние 38% радиуса; каждые 7с угроза 120° вспыхивает через 1.5с телеграфа, урон 0.25× макс. корпуса/с, 1.8с; щит блокирует; угроза вращается 0.5 рад/с. Раскладка меняется от удара к удару: одна полоса из 6 долей, две зоны по 3 доли напротив друг друга или три зоны по 2 доли через 120°; промежутки между зонами одинаковые |

### 4.3. Спавн

- 30% врагов спавнятся сразу.
- Далее подкрепления по 10% каждые 10% убийств, 2–5 разломов.
- Место разломов: 0.55–1.0 от (R − 100), не ближе 220 px к игроку, преимущественно с дальней стороны.
- **Клещи (pincer) [P1]:** 25% подкреплений спавнятся на дуге впереди игрока по направлению обхода (±0.6 рад, 0.8R), минимум 260 px от игрока.

### 4.4. Якоря-разломы (Anchors)

Якорь — не просто объектив, а источник угрозы: он держит разлом открытым.

- **Постановка:** 2–3 якоря появляются только после активации зоны — на 0.58R от её центра, на дальней от игрока стороне, с разносом по дуге ±0.75 рад. До активации зоны якорей нет: у арены ещё нет геометрии.
- **Держат разлом:** пока якорь жив, каждые 6с из его точки выходит подкрепление (до 12 на якорь за волну). Снятый якорь закрывает свой поток.
- **Завершение волны:** волна не заканчивается, пока жив хотя бы один якорь. Все сняты → завершение волны и +40% деталей.
- **HP:** `240 + 28·wave` (≈ 324 на 3-й, ≈ 800 на 20-й волне), скейл как у крейсера.
- **Награда за снятый якорь:** детали в размере 15% его HP — выгода видна до конца волны.
- **Цель всегда внутри арены:** при сжатии зоны якоря проецируются внутрь 0.8R.
- **Стрельба:** автонаведение выбирает якорь целью в радиусе 620px, если рядом нет угрозы (враг ближе 240px приоритетнее).
- **Читаемость:** пульсирующий ореол разлома, вращающееся кольцо, кольцо прочности по HP; HUD показывает число живых якорей, тост объясняет правило.

### 4.5. Пауза между волнами

- Волна зачищена → **ангар** открывается сразу, мир ставится на паузу.
- В ангаре: магазин забега (корпус, скорость, оружие, дроны, щит, темп огня).
- «Продолжить забег» снимает паузу: показывается баннер зачистки (1.5с), затем следующая волна (4.0с от зачистки).
- Отсчёт следующей волны не накладывается на баннер.
- Наследие выдаёт сама игра: после зачистки первой волны, между баннером зачистки и отсчётом следующей, показывается карточка случайного артефакта — игрок её только подтверждает. Доктрину выдаёт босс-волна: после исчезновения баннера зачистки и до отсчёта следующей волны игрок выбирает одну из двух карточек.

### 5.1. Базовые архетипы (6 видов)

| Вид | Скорость (×скорости игрока) | Угроза | Поведение | Контрприём |
|---|---|---|---|---|
| **Дрон (Drone)** | 0.93× (+линейный рост) | Контакт 12×урон | Рой: кольцо 0.55R, отделение 1–2 дронов на 1.6с каждые 4–6с, leash 520px. Скорость кольца растёт с числом дронов в группе (×0.8…×2.2); новая группа идёт на 55 % и разгоняется до полной за 8с; в атаке дрон идёт на полной базовой | Убить или улететь |
| **Хантер (Hunter)** | 1.15× | Контакт 32×урон | Перехват → замах 0.35с → рывок 1.4× 1.0с → восстановление 0.8с | Уйти в сторону на форсаже |
| **Истребитель (Fighter)** | 0.9× | Болт 4.55×урон, 720px/s, очередь 2–4, пауза 2с | Патруль → поиск → заход → выстрел → вираж; при облёте — срез орбиты (CUT) | Сломать облёт, уйти с линии |
| **Крейсер (Cruiser)** | 0.5× | 2 турели, болт 12×урон, 436.8px/s, темп 2.6/(3+0.04w) | Эскорт носителя или точка упреждения; таран 2.4× скорости | Не стоять на линии, использовать паузу после тарана |

| **Минёр (Miner)** | 0.55× | 3 мины за заход (≤6 на арене), контакт 14 | Патруль по кольцу 0.78R → заход на орбиту 150px → мина → отход 3с | Не летать по предсказуемой орбите; расстрелять мины (3 HP) |

**Мина (Mine):** неподвижна, вращается, живёт 18с, контакт 22×урон, 3 HP, гаснет сама.

### 5.3. Элитные модификаторы (Affixes) [P1]

Шанс элиты: 8% на волне, 1 гарантированный элитный «пак» каждые 5 волн. Аффиксы складываются с видом.

| Аффикс | Эффект | Визуальная метка |
|---|---|---|
| **Бронированный (Armored)** | +50% HP, −20% скорость | Серая обводка |
| **Летучий (Volatile)** | При смерти взрыв: радиус 80px, урон 1.2× контакта (на ранних волнах ≈ треть корпуса), но не больше 35% макс. корпуса игрока | Оранжевый мигающий контур |
| **Щитовой (Shielded)** | Блокирует первый удар (HP щита = 30% макс. HP) | Голубой пузырь |
| **Вампирский (Vampiric)** | Лечится на 5% от нанесённого урона | Красные частицы |
| **Ускоренный (Hasted)** | +40% скорость, +20% скорострельность | Жёлтый след |
| **Делящийся (Splitting)** | При смерти делится на 2 (как Дезинтегратор) | Фиолетовый оттенок |
| **Меткий (Precise)** | +50% меткость, +20% урон снарядов | Зелёный прицел |
| **Регенерирующий (Regenerating)** | Восстанавливает 2% HP/с | Зелёная аура |

### 5.4. Боссы [P1]

- Появляются на волнах 10, 20, 30, 40, ...
- HP ≈ 12–15% от суммы HP волны.
- 2–3 фазы по 20–30с каждая.
- Свои правила: вращающиеся лучи, смена безопасного сектора, вызов роя.
- Отдельная музыка и баннер.
- Награда: реликвия/доктрина + бонус деталей ×2.
- **Не проходится облётом края** (урон/мин облёта ≥ 1.5× текущего).

**Босс 1 (волна 10): «Страж Периметра»**  
- Фаза 1: вращающийся лазер (период 6с, радиус 400px).  
- Фаза 2: призыв 2 носителей + рой.  
- Фаза 3: сжатие зоны до 0.5R + ускоренные истребители.

**Босс 2 (волна 20): «Колосс»**  
- Фаза 1: 4 турели по углам, стреляют секторами.  
- Фаза 2: таран (2.4× скорость) + призыв крейсеров.  
- Фаза 3: «гравитационная воронка» — притягивает игрока к центру.

**Босс 3 (волна 30): «Улей»**  
- Фаза 1: матка-улья + постоянный спавн дронов.  
- Фаза 2: делится на 3 матки.  
- Фаза 3: «рой-шторм» — весь экран заполняется дронами на 10с.

**Боссы 4+ (волна 40+):** бесконечный скейл, комбинации механик предыдущих боссов.

### 5.5. ИИ и поведение

- **Директор угроз (Threat Director):** глобальный координатор выдаёт «жетоны атаки». Одновременно атаковать могут: ≤1 хантер, ≤2 истребителя, ≤1 крейсер, ≤4 отделившихся дрона, всего ≤8 активных угроз в радиусе 260px. Остальные держат дистанцию и «заряжаются» (телеграф). Жетоны перераспределяются каждые 1.5с.
- **Отворачивание от края:** ослаблено. `AVOID_ZONE_RADIUS` 160→70, `AVOID_HARD` 60→30, хантер 90→40, крейсер 1.5→0.8 радиуса. Если игрок в внешней трети зоны — отворачивание ослабляется на 70%.
- **Телеграфы (грамматика):**
  - Красная линия → уйти в сторону (хантер, таран).
  - Оранжевый конус → покинуть сектор (турели крейсера).
  - Белая вспышка → поднять щит (залп истребителя).
  - Фиолетовая дуга → разорвать дистанцию/включить форсаж (tether, гарпунщик).

## 6. Оружие и дроны

### 6.1. Базовое оружие (4 вида)

## 7. Защитные и позиционные глаголы

### 7.1. Форсаж (Boost) [P0] — реализовано

Кнопка на таче: только иконка, без подписи. Заполнение показывает кольцо
вокруг иконки, цвет кнопки — состояние.

- **Заряд:** каждое убийство врага даёт 1/12 энергии; 12 убийств — полное кольцо.
- **Готовность:** серая и не работает, пока кольцо не заполнено полностью.
- **Активация:** при полном заряде кнопка становится активной (Shift или кнопка).
- **Разгон:** +45% к пределу скорости и тяге; энергия тратится 1/3 запаса в секунду
  (полного кольца хватает на 3 секунды).
- **Истощение:** на нуле форсаж выключается, кольцо пустое, кнопка снова копит заряд.
- **Без неуязвимости:** форсаж — про скорость и позицию, а не про отмену урона.
- Убийства во время разгона не добавляют энергию.
- Ввод: Shift (клавиатура) / кнопка на таче.
- HUD: кольцо энергии вокруг иконки кнопки.

### 7.2. Активный щит [P1]

- Удержание: проецирует сектор 120° (→180° с прокачкой), блокирует 100% урона из сектора.
- Дренаж: 30 энергии/с.
- Пассивный блок: 8% (было 5–40%).
- Перезагрузка: 3с при полном истощении.
- Прокачка: ширина сектора, запас энергии, реген.

### 7.3. Выбор цели (Lock-on) [P1]

- Лок цели (Tab / правый стик / тап): переопределяет автонаведение.
- Лок живёт до смерти цели или 5с без линии видимости.
- Дроны и ракеты идут по локу.
- Индикатор лока в HUD (рамка вокруг цели).

### 7.4. Приказы дронам [P1]

- 3 режима: сопровождение / штурм / удержание точки.
- Переключение: клавиши 1/2/3 или кнопки на таче.
- Индикатор режима в HUD.

### 7.5. Квантовая подмена (Quantum Swap)

- Телепорт местами с ближайшим врагом (до 520px).
- КД 8с.
- Выдаётся пикапом носителя.
- [P1] Добавить как мета-способность (покупка за кредиты).

## 11. Наследие (Legacy Artifacts)

Артефакты **не выбираются в меню и не покупаются**: после зачистки **первой волны забега** игра выдаёт **один случайный артефакт**. Между баннером «волна пройдена» и отсчётом следующей волны появляется карточка с именем и эффектом артефакта; отсчёт ждёт, пока игрок её не закроет, — мир на это время стоит.

Правила:

- **Одна карточка на забег.** Артефакт действует сразу после выдачи и до конца текущего забега; сила бонуса определяет редкость (см. 11.1).
- **Без переноса.** Новый забег всегда начинается без наследия: в мету ничего не пишется.
- **Складывается с остальным.** Бонус артефакта применяется поверх прокачки забега, доктрины и талантов Эха Разлома теми же множителями.
- **Детерминизм.** Случайный выбор идёт из seed-потока мира (`drops`), поэтому запись и симуляция воспроизводятся один в один.
- **Тестовые волны.** В отладочных и single-wave прогонах наследие не выдаётся.

### 11.1. Редкость

Артефакт выпадает по весам редкости: **обычный — 10, редкий — 5, эпический — 2**. Вес делится на сумму весов всех 12 артефактов (76), поэтому шансы такие:

- **обычные** — ~66% (5 артефактов);
- **редкие** — ~26% (4 артефакта);
- **эпические** — ~8% (3 артефакта).

Сильные бонусы (лишний слот, двойной сдвиг щита, двойной бонус к скорости и темпу) сделаны редкими, чтобы одна карточка на забег не превращалась в гарантированный сильный артефакт. Выбор — один бросок seed-потока `drops` со взвешенным вычитанием весов: одинаковый seed всегда даёт один и тот же артефакт.

## 12. Асценсия (Threat Levels)

### 12.1. Структура

- **TL 0:** базовая игра (без модификаторов).
- **TL 1+:** открывается после зачистки 10-й волны (`bestWave >= 10`).
- Игрок собирает TL из **модификаторов**: у каждого своя стоимость.
- Максимум — 20 TL. Сумма всех модификаторов ровно 20, поэтому «включить всё»
  и есть предельная угроза.
- Набор хранится в `rift9_ascension` (JSON-массив id) и применяется со
  следующего забега: смена в меню не ломает текущий.

| 10 | **Боссы чаще (Frequent Bosses)** | Босс каждые 5 волн вместо 10 | 2 |
| 11 | **Клещи (Pincer)** | Каждое второе подкрепление — пара с двух сторон | 1 |
| 12 | **Без подбора (No Magnet)** | −50% радиус магнита подбора | 1 |
| 13 | **Хардкор (Hardcore Mode)** | Лечения нет, ×3 кредитов | 3 |
| 14 | **Зеркальный мир (Mirror World)** | Враги входят и маневрируют зеркально | 2 |
| 15 | **Бесконечный скейл (Endless Scaling)** | После 40-й волны враги продолжают расти | 2 |

Эффекты задаются в `meta/ascension.ts` как `AscensionEffects` и попадают в
мир через `GameParams.ascension` (`resolveParams`), поэтому все системы
читают один и тот же снимок сложности.

### 12.3. Награды асценсии

- TL 1–5: +10% кредитов за забег за каждый TL.
- TL 6–10: +5% деталей за забег за каждый TL выше пятого.
- Хардкор: ×3 кредитов поверх бонуса TL.
- TL 11–20: открываются доктрины и артефакты с требованием по угрозе.
  Они входят в пул только когда текущий TL не ниже требования, поэтому
  обычная сложность баланс не меняет.

| TL | Награда | Эффект |
|---|---|---|
| 11 | Доктрина «Осадный контур» | +1 слот оружия, +12% темпа огня, −10% скорости |
| 12 | Артефакт «Ядро разлома» | +3 уровня блока щита, +2 восстановления |
| 14 | Доктрина «Пепельный щит» | +2 уровня блока щита, +10% корпуса, −10% деталей |
| 15 | Артефакт «Клеймо охотника» | +20% темпа огня, +10% скорости |

Требование живёт в данных (`minThreatLevel` у доктрины/артефакта), пул

- TL 16–20: косметика и TL 20+: таблица лидеров — **[P2]**: такого контента

## 13. Арены и события

### 13.1. Базовая арена

- Круговая зона, радиус 380–650px.
- Зона расширяется со скоростью 1.3× игрока.
- Урон вне зоны: 10% макс. HP/с.

| **Квадрат (Square)** | Зона квадратная, углы опасны (буря сильнее в углах) |
| **Кольцо (Ring)** | Зона — кольцо (центр занят, игрок не может пройти через центр) |

| **Вращение (Rotating)** | Зона вращается (0.1 рад/с) |
| **Порталы (Portals)** | 2 портала на противоположных сторонах, телепортируют игрока и врагов |

| **Босс (Boss)** | Босс-волна | Каждые 10 волн (5 при TL) |

## 14. UI/UX и читаемость

### 14.1. HUD

- **HP-бар** (верхний левый): текущий/макс. HP, цвет: зелёный → жёлтый → красный.
- **Щит-бар** (под HP): энергия щита, сектор активного щита (если активен).
- **Детали** (верхний правый): текущие детали забега.
- **Волна** (верхний центр): номер волны, таймер волны (если Time Attack).
- **Индикатор форсажа** (кнопка на таче): кольцо вокруг иконки, заполняется убийствами и убывает при разгоне.
- **Индикатор лока** (рамка вокруг цели): если лок активен.
- **Режим дронов** (иконка): сопровождение/штурм/удержание.
- **Радар** (правый нижний угол, 96px): зона, разломы, якоря, элиты, носители, босс. Обновление 15 Гц.
- **Индикаторы за кадром:** вспышка на кромке экрана при зарядке атаки вне кадра.

### 14.2. Телеграфы (грамматика)

| Цвет/форма | Значение | Ответ |
|---|---|---|
| Красная линия | Удар (хантер, таран) | Уйти в сторону |
| Оранжевый конус | Залп (турели) | Покинуть сектор |
| Белая вспышка | Залп истребителя | Поднять щит |
| Фиолетовая дуга | Tether/гарпун | Рывок/разрыв |
| Жёлтый круг | Взрыв (летучий) | Отойти |
| Синий пузырь | Щитовой враг | Сфокусировать |

### 14.3. Экраны

- **Главное меню:** Новый забег, Мета-дерево, Арсенал, Наследие, Асценсия, Рекорды, Настройки.
- **Экран забега:** HUD + игровое поле.
- **Магазин между волнами:** сетка улучшений, цены, баланс деталей, реролл.
- **Экран смерти:** причина смерти, статистика (волна, убийства, детали, кредиты получены, разблокировки), кнопка «Ещё раз».
- **Экран победы (босс):** статистика + награды + выбор: продолжить / забрать кредиты.
- **Экран мета-дерева:** Зеркало Ночи, ветки, стоимости.
- **Экран арсенала:** оружие, дроны, линии прокачки.
- **Выбор доктрины:** две карточки после босс-волны, мир на паузе до выбора.
- **Карточка наследия:** артефакт, выданный после первой волны (имя, эффект, «Продолжить»).
- **Экран асценсии:** TL, модификаторы, награды.

## 16. Технические требования (кратко)

### 16.1. Архитектура

- ECS-система (@trixt0r/ecs) для игровых сущностей.
- Системы: PlayerMovement, EnemyAI, WeaponManager, ShieldSystem, PickupDropSystem, ScoringSystem, ThreatDirector, ZoneSystem, WaveOrchestrator.
- Рендер: picogl (WebGL).
- Физика: planck (2D).
- Хранение: localStorage (PersistencePort) для мета, деталей, рекордов.

### 16.2. Производительность

- 60 FPS при 100+ врагах на экране.
- Пул объектов для пуль, частиц, врагов.
- Лимит активных вражеских снарядов ≤ 30 (p90).
- Макс. атакующих в радиусе 260px ≤ 8.

### 16.3. Ввод

- Клавиатура: WASD/стрелки (тяга), Shift (форсаж), ЛКМ/ПКМ (основной/альтернативный огонь), Space (способность), T (тактический режим), Esc/P (пауза).
- Геймпад: левый стик (тяга), A/B (подтвердить/назад), LB/RB (вкладки), Start (пауза).
- Тач: виртуальный джойстик + кнопки.

### 16.4. Сохранение

- `localStorage` ключи: upgrades, bestWave, weaponLoadout, metaTree, unlocks, doctrines, legacy, threatLevel, stats.
- Автосохранение после каждого забега.
- Экспорт/импорт сохранения (JSON).
